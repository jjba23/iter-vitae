All notable changes to this project will be documented in this file. Changes are listed per project release (tag) and within each tag there are details about changes, additions, fixes and removals.

This project adheres loosely to [[https://semver.org/spec/v2.0.0.html][Semantic Versioning]].

*[Unreleased]*

*** Added

- `--init` (`-i`): an interactive wizard that builds a persona file. It covers every content field (contact details, links, address, summary, skills, jobs, education, languages, interests and driving licences), lets you choose a theme, offers an optional step for renaming section headings, shows a review before writing, and asks before overwriting an existing file. It uses `./my-cv.scm` when `--file` is omitted.
- The wizard can build a persona in several languages. It asks for a comma-separated list of locale codes, asks each translatable question once per language (pressing Enter reuses the first language), and writes real translation alists instead of an `(all . "...")` fallback. The new `--locales` option pre-answers the language question, for example `iter-vitae --init --locales en,nl,es`.
- The generated language-proficiency table now follows the selected document locales, with English, Dutch and Spanish labels built in.
- `--all-locales`: render one document for every locale defined in the persona, writing each into its own directory below `--destination` (for example `dist/en/index.html` and `dist/nl/index.html`). The same layout applies to `--format text`.
- The wizard uses colours, emoji section markers and plain-language hints in a terminal; styling is disabled automatically when output is redirected and can be turned off with `NO_COLOR=1`.
- Optional `profile-picture` support. A persona can point at a local PNG, JPEG, WebP, GIF, AVIF or SVG image, an `https://` URL or a `data:image/...` URI. Local files are embedded as data URIs so the generated CV remains one self-contained HTML file. `fatum`, `ef-cyprus` and `fundamental` show a round portrait beside the name; `ats` omits it.
- Language proficiency now uses the standard five-level CV scale: elementary, limited working, professional, full professional, and native/bilingual. The default labels cover English, Dutch and Spanish, and `language-proficiency-label` is shared by every renderer. The visual tables gained a localized language-column header, and the ATS/plain-text output spells each level out in words.

*** Modified

- The README was reorganized around a generated four-theme demo, with a reproducible `scripts/generate-demo` workflow and no legacy remote screenshots or logos. Installation, usage, theme and field-reference material was preserved and expanded.
- All visual themes now render the optional `skills` field: `fatum` and `ef-cyprus` as tag rows, `fundamental` as a comma-separated line. Date ranges written with `=>` display as an en dash in visual themes.
- `fatum` gained a printable card layout, hairline section rules, monospaced skill tags, a lighter language table and A4 print rules. `ef-cyprus` gained matching green-accented tags and print rules, while `fundamental` received a tighter type scale, print styles and footer markup. `ats` keeps entries from splitting across printed pages. The README tour now opens with `ats` (the ATS-safe version) before the visual themes, and the demo frames are tall enough to show the full page.
- The visual themes now share a consistent portrait header, and `fatum` is centred at a readable width on wide screens. Job titles and language tables now receive their full face styling instead of a literal class name. The bundled personas have cleaner commentary, named education entries and more consistent translations.
- The project is now licensed under the MIT License, including its documentation and examples. Sources and build files carry the consistent `SPDX-License-Identifier: MIT` header (`;; iter-vitae` in Scheme, `# iter-vitae` elsewhere) instead of the full licence boilerplate, and the Arch and openSUSE recipes install the top-level `LICENSE` file (`debian/copyright` remains the Debian licence record).

*** Fixed

- All themes now declare the document language, accept bare job-title links and normalize them to `https://`, and list language proficiency columns in reading, speaking, writing order.
- The `ats` theme removes the stray space left before punctuation when it strips an emoji, joins sentence-style interests with a space, and opens external links safely.
- The English short-intro heading is now punctuated as "Who am I?". Section headings and the driving-licence copy were tightened across English, Dutch and Spanish (for example "Driving licence" is no longer repeated in the value).
- Persona files generated by the wizard now use the renderer's `languages` shape, so language names and proficiency levels no longer come out empty.
- The wizard's generated header now uses the persona name and locale in the right places and quotes the example portrait path correctly.

*[Released]*

** v1.0.1 (2026-10-22)

*** Added

- `ats` theme: a single-column, plain-text-first resume for US applicant tracking systems and automated screeners, with conventional section headings, Arial/Helvetica typography and no tables, images, icons or external assets.
- `skills` persona field, rendered as a comma-separated keyword line by the `ats` theme.
- `--format text`: a plain-text output mode that writes `resume.txt` for employers that only accept text uploads. It shares the ATS section order and cleanup, and ignores the visual theme.
