Generate a curriculum vitae from a persona file.

Usage: iter-vitae [OPTIONS]

Options:
    -l, --locale LOCALE          Specify the locale (e.g., 'en', 'es'). Defaults to 'en'
    -o, --output-dir DIRECTORY   Specify the output directory for the generated CV.
    -p, --persona-file FILE      Specify the persona file (required).
    -h, --help                   Display this help message and exit.

Examples:
    iter-vitae --locale en --persona-file ~/Documents/my-cv.scm --output-dir ~/Documents
