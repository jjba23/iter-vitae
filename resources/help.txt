Iter Vitae:
    Generate an attractive, modern and customizable Curriculum Vitae / Resume.

    See more at: https://codeberg.org/jjba23/iter-vitae
    Software licensed under the MIT License.

USAGE: iter-vitae [OPTIONS]
OPTIONS:
    -f, --file FILE
        Specify the path to Scheme config file (required, unless --init).

    -i, --init
        Start an interactive wizard that asks about your CV and writes a
        persona file. Combined with --file, that path is created; without
        it, ./my-cv.scm is written.

    -l, --locale LOCALE
        Specify the locale (e.g., 'en', 'nl'). Defaults to 'en'.

    --locales CODES
        Comma-separated languages for the --init wizard, e.g. en,nl,es.
        The first code is the main language used for the questions. When
        omitted, the wizard asks for the languages and defaults to --locale.

    --all-locales
        Render one CV for every locale defined in the persona. Each output
        goes into its own directory, e.g. ./dist/en/ and ./dist/nl/.

    --all-themes
        Render every built-in theme. Each output goes into its own directory:
        ./dist/ats/, ./dist/fatum/, ./dist/ef-cyprus/ and
        ./dist/fundamental/. Combine with --all-locales for
        ./dist/THEME/LOCALE/. Plain text cannot be combined with this option.

    -d, --destination DIRECTORY
        Specify the output directory for the generated CV. Defaults to "./dist".

    -F, --format FORMAT
        Select the output format:
          html  index.html (default)
          text  resume.txt for text-only uploads
          pdf   resume.pdf, printed on A4 by headless Chromium/Chrome
        PDF output needs Google Chrome, Chromium, Edge or Brave. Set
        ITER_VITAE_BROWSER to the executable if it is not found.

    -r, --resources DIRECTORY
        Where the bundled stylesheets live. Normally detected automatically.

    -h, --help
        Display this help message and exit.

+----------------------------------------------------------------------------+
EXAMPLES:
    iter-vitae --init --file ~/documents/my-cv.scm

    iter-vitae --init --locales en,nl,es --file ~/documents/my-cv.scm

    iter-vitae --all-locales -f ~/documents/my-cv.scm -d ~/documents/dist

    iter-vitae -l nl -f ~/documents/my-cv.scm -d ~/documents/dist

    iter-vitae --format pdf \
        -f ~/documents/my-cv.scm -d ~/documents/dist

    iter-vitae --all-themes --format pdf \
        -f ~/documents/my-cv.scm -d ~/documents/comparison

    iter-vitae --all-themes --all-locales --format pdf \
        -f ~/documents/my-cv.scm -d ~/documents/comparison
